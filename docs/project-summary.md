# RTI Online

Every Indian citizen can ask a government office for its records. Almost nobody
does, and the reason is not apathy. To file an RTI you have to know which of
thousands of public authorities holds the papers you want, and you have to word
the request as a demand for documents rather than a question. Get either part
wrong and it comes back weeks later, or gets transferred, and your thirty day
clock starts again.

The official portal assumes you know all this before you arrive. It opens with
a dropdown of ministries. Anyone who already knows which ministry to pick did
not need much help to begin with.

We start from the other end. You describe what happened in your own words. We
find the office holding the records, rewrite it into a request the Act obliges
someone to answer, and watch the deadline for you.

Three things make it better. Routing is grounded in a hand curated directory,
so the system can only name offices that exist, never one it invented. It
scores its own confidence and says plainly when it is unsure, because a
confident wrong answer costs a citizen a month. And when thirty days pass with
no reply, the first appeal is already drafted, free, and waiting.

It works in English and Hindi, on a phone, at any text size, without an
account. Filing is simulated. We prepare the application and you file it, and
we say so on screen, not in a footer.
