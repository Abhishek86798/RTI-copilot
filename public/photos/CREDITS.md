# Photograph credits

Every photograph in this directory is a documentary image reused from
Wikimedia Commons under an open licence. They are editorial and illustrative:
none of them depicts an actual RTI applicant, and no person shown has any
connection to this project or has been presented as a user of it.

Each is converted to greyscale and re-encoded as WebP for this site. The
originals are linked below. Attribution is required by these licences and is
shown on the page beside each image as well as here.

Nothing in this directory is a Government of India asset, and no government
endorsement is implied. Where a photograph happens to include official
signage, that is incidental to a documentary picture of a public place.

## Re-running

These were selected by hand from the Wikimedia Commons API and processed with
a centre-crop, greyscale conversion, a slight contrast lift and a WebP
re-encode at quality 70. The three sources together weigh roughly 395 KB,
which is the budget that matters on the connections this product is built for.
